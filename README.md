# Salesforce Company Settings Configuration

## Project Overview

This project demonstrates Salesforce Company Settings configuration for a multinational organization.

## Topics Covered

- Fiscal Year
- Business Hours
- Currency Management
- Multiple Currencies
- Corporate Currency
- Advanced Currency Management
- Default Settings

## Business Scenario

GlobalTech Solutions operates in the USA, UK, and India.

The project demonstrates how to configure Salesforce Company Settings to support global business operations.
